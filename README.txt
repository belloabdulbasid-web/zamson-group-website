# Zamson Group Website V3

## Preview
Open `index.html` in a modern browser. Keep the `assets`, `css`, and `js` folders beside the HTML pages.

## Pages
- Home
- About
- Businesses
- Operations
- Leadership
- Contact
- Zamson Global Resources profile
- Zamson Oil & Gas profile
- Zamson Transport profile

## Included
- Original Zamson photographs supplied for this project
- Original logo and Managing Director portrait
- Supplied head-office video in MP4 format
- Responsive navigation and mobile menu
- Enquiry form that opens the visitor's email application

## Before publishing
Confirm the official company phone, email, address, company history, business descriptions, executive name/title, and any statistics. The enquiry form currently uses `mailto:` without a configured recipient address. Add the approved recipient email before launch.
